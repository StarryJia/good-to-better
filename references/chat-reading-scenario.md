# 聊天阅读场景示例

以下全部为合成数据，帮助建立可重放的场景，不是所有产品必须支持的功能，也不是实际模型性能结果。其他产品换成自己的核心任务。

## 固定输入

原始聊天四条：

1. 朋友：我有点担心准备不完。
2. 本人：现在最卡住的是哪一部分？
3. 朋友：主要是开头，讲了几次都觉得不顺。
4. 本人：明晚九点我听你讲。你想先听建议，还是先说说？

提问：这段示例里，我怎样回应了朋友？

固定回答：

```markdown
你提供了具体时间，也给对方保留了选择。

### 这段记录里发生了什么
朋友担心准备不完。你先确认卡住的部分，再提出明晚九点一起看材料。

### 可以观察到的行为
- 确认对方需要什么。
- 提供具体时间与行动。
- 保留选择和调整的空间。

| 原文线索 | 有限观察 |
| --- | --- |
| 明晚九点我听你讲 | 提供具体可执行的支持 |
| 想先听建议还是先说说 | 尊重对方当下需要 |

这些只说明这段示例中的行为，不能据此判断稳定人格。
```

另备短回答：`你提供了具体时间，也给对方保留选择。`

模型甲与模型乙必须有不同的稳定编号，显示名包含一个足够长的名称。固定统计示例：输出 100、总耗时 10 秒、首次输出等待 9 秒。若产品采用这两种速度，模型生成速度应为每秒 100，端到端速度应为每秒 10；先确认两个产品的统计定义再比较。缺失等待时间的变体只用于验证未知值，不填零。

## 场景表

| 编号 | 操作 | 需要观察的结果 |
| --- | --- | --- |
| S01 | 用甲发送固定问题，流式返回固定长回答，读到末尾 | 标题、三条列表、表格可读；普通窗口中主阅读区明确 |
| S02 | 向上读旧段落，再到达新的输出 | 阅读位置稳定；返回最新内容的方法可发现 |
| S03 | 打开历史、切换另一条、再返回 | 正文、输入草稿和引用归属正确；关闭后空间与焦点合理 |
| S04 | 将下一次使用的模型改成乙，再读甲的回答 | 旧回答与下一次模型不会混淆，长名称可辨认 |
| S05 | 打开和收起同一回答的统计 | 数字的含义、单位和主次一致；未知值保持未知 |
| S06 | 提取整条回答，例如复制到测试文本框 | 完整内容不遗漏，不混入模型名、统计或下一条问题 |
| S07 | 服务返回合成失败，写新草稿，重试原请求 | 新草稿和引用保留，无重复问题；真实恢复结果可见 |
| S08 | 生成中停止；取消未提交的模型目录选择 | 保留真实部分结果；未提交选择不被保存 |
| S09 | 改成项目支持的窄窗口，重复阅读、选模、统计、关闭返回 | 内容和主要操作可达，表格不撑破整个页面 |

不适用的场景写明原因；不能为了凑齐表格扩展产品功能。若只拿到两张完成态截图，可以评估 S01 的视觉结果，其余操作保持未验证。

## 复评方式

保留同一输入、版本记录和场景编号，新增修复后证据。读完表格后继续执行 S04、S05、S06 与适用的异常场景，确保修复格式没有破坏模型归属、统计、复制或草稿。用户接受的新约定才进入有效基线。

## 桌面环境记录

使用隔离配置时，先建立程序启动所需的目录并确认实际资料路径，再导入合成数据。保留测试进程编号、端口、临时目录、启动和关闭方法。桌面截图接口失败可以换用应用支持的本机调试连接；原始失败及回退方式都写入报告。缺少工具能力时停止依赖该能力的结论，而不是模拟点击成功。
